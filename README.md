### About Me

I am a Full-Stack Developer focused on building end-to-end solutions that drive business efficiency. With a solid foundation in backend architectures and cloud infrastructure, I navigate the entire stack to deliver secure, responsive, and scalable applications. 

Great software goes beyond writing code—it requires understanding the business to deliver measurable impact. Here is how I apply this:

* **AçaíLoop:** Developed a B2B green logistics platform for sustainable biomass reuse. Architected the backend using Python and Flask with Clean Architecture principles, integrated with Supabase, and built a Mobile First frontend with React and Tailwind CSS.
* **CathPed:** Built a patient management system for pediatric cardiology that centralized clinical data and automated workflows. By replacing manual spreadsheet processes, the system increased medical operational efficiency by 30%.
* **GreenShelf:** Created a full-stack application aligned with UN SDG 12 to reduce retail food waste. I worked directly with local supermarket owners to map workflows and translate messy business processes into a clean software system.
* **Cloud Architecture:** Designed and deployed a highly performant web architecture using AWS S3 and CloudFront (CDN) with a fully automated CI/CD pipeline, applying concepts from my AWS Cloud Practitioner preparation.
